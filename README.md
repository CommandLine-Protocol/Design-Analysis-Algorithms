## Running the Algorithm Explorer

1. Navigate to the `algorithms_explorer` directory:
   ```bash
   cd algorithms_explorer
   ```

2. Start the server:
   ```bash
   node server.js
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
